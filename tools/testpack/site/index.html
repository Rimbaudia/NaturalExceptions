Natural Exceptions

A systems-driven absurdity sandbox, where experimentation is the main way forward.

Minecraft 1.7.10 Forge 10.13.4.1614 Java 21 Version @VERSION@

Install with Prism Launcher

  1. Install Prism Launcher and sign in with your Microsoft account.
  2. Choose Add Instance → Import and paste this link:
    @BASE@/NaturalExceptions-Test.zip
  3. Press Play. If Prism asks for Java 21, let it download it.

Every time you press Play, the instance updates itself to the newest build, along with the mods it needs. The first launch downloads everything, so it takes a while.

Play together

Everyone joining needs the instance above. To host a dedicated server on Linux with Java 21, run tools/testpack/make-server.sh from the source, as described in the server guide.

Installing by hand

For your own Forge 1.7.10 setup on Java 21, put these in mods:

Natural Exceptions@VERSION@
UniMixins0.3.1
GTNHLib and GTNHExtLib0.11.54, 1.0.5
Hodgepodge2.7.216
Lumi, ChunkAPI, FalsePatternLib1.2.2, 0.8.4, 1.12.2
Angelica (client only)2.2.33
lwjgl3ify3.0.33

Natural Exceptions will not start without them. Running Java 21 also needs lwjgl3ify's launcher; the Prism instance has it set up already.
